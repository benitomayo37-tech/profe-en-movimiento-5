ELIMINAR LA FOTOGRAFIA PERSONAL DEL DASHBOARD

Resultado:
- Dashboard sin fotografia personal.
- Profe IA sin fotografia personal.
- Robot de Profe IA conservado.
- Botones, textos, rutas y herramientas sin cambios.

PASOS

1. Copia aplicar-eliminar-foto-dashboard.ps1 dentro de:
   C:\Users\Usuario\profe-en-movimiento-5

2. Ejecuta en PowerShell:
   powershell -ExecutionPolicy Bypass -File .\aplicar-eliminar-foto-dashboard.ps1

3. Ejecuta:
   npm run lint

4. Ejecuta:
   npm run build

5. Solo después de confirmar el build, despliega a producción.
