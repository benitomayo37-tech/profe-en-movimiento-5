**Nombre del proyecto:** Profe en Movimiento 5.0

**Tipo de producto:** Plataforma educativa digital para docentes de Educación Física  

---

# 1. Visión general

Profe en Movimiento 5.0 es una plataforma educativa diseñada para facilitar el trabajo de los docentes de Educación Física mediante recursos pedagógicos, formación profesional, herramientas digitales, inteligencia artificial y productos educativos.

La plataforma busca reunir en un solo ecosistema soluciones que normalmente se encuentran dispersas en diferentes sitios, archivos y aplicaciones.

El objetivo no es construir únicamente una página web, sino desarrollar una herramienta de trabajo útil, escalable y sostenible para la comunidad educativa.

---

# 2. Misión

Transformar la Educación Física mediante tecnología, inteligencia artificial y recursos educativos de alta calidad que faciliten la planificación, la evaluación y el desarrollo profesional docente.

---

# 3. Visión

Convertirse en una plataforma de referencia para docentes de Educación Física en el mundo hispanohablante.

Profe en Movimiento aspira a ser reconocida por su utilidad, innovación, calidad pedagógica, facilidad de uso y capacidad para adaptarse a las necesidades reales de los educadores.

---

# 4. Lema interno

> Cada línea de código debe facilitar la vida de un docente.

Este principio orientará las decisiones de diseño, desarrollo y evolución del producto.

Toda nueva funcionalidad deberá responder a una necesidad educativa concreta y aportar valor real a los usuarios.

---

# 5. Problemas que busca resolver

Los docentes de Educación Física enfrentan dificultades frecuentes como:

- Falta de tiempo para crear planificaciones.
- Recursos educativos dispersos.
- Dificultad para diseñar instrumentos de evaluación.
- Escasez de materiales adaptados a grupos numerosos.
- Poca disponibilidad de herramientas especializadas.
- Necesidad de aplicar metodologías como DUA.
- Falta de recursos para estudiantes con necesidades educativas específicas.
- Dificultad para organizar documentos, evaluaciones y actividades.
- Acceso limitado a formación profesional especializada.
- Uso de inteligencia artificial sin orientación pedagógica específica.

Profe en Movimiento busca ofrecer soluciones prácticas para cada uno de estos problemas.

# 12. Principios del producto

## Utilidad

Cada función debe resolver una necesidad real.

## Simplicidad

La plataforma debe ser fácil de usar incluso para personas con poca experiencia tecnológica.

## Calidad

Los recursos deben mantener estándares pedagógicos y visuales elevados.

## Accesibilidad

El producto debe poder ser utilizado por la mayor cantidad posible de personas.

## Escalabilidad

La arquitectura debe permitir incorporar nuevas funciones sin reconstruir todo el sistema.

## Consistencia

La experiencia visual y funcional debe mantenerse uniforme.

## Seguridad

La información de los usuarios debe tratarse de manera responsable.

## Evolución continua

La plataforma será un producto vivo, mejorado mediante versiones y retroalimentación.

---

# 15. Criterios para aceptar nuevas funciones

Antes de incorporar una nueva función se evaluará:

- ¿Resuelve una necesidad real?
- ¿Facilita el trabajo docente?
- ¿Es coherente con la visión?
- ¿Puede mantenerse a largo plazo?
- ¿Es segura?
- ¿Es accesible?
- ¿Aporta valor suficiente?
- ¿Es prioritaria para la versión actual?

Las ideas que no sean prioritarias se registrarán para versiones futuras.
