INSTALACIÓN
1. Cierra el servidor local si está funcionando.
2. Extrae el ZIP.
3. Copia las carpetas app y features sobre:
   C:\Users\Usuario\profe-en-movimiento-5
4. Cuando Windows pregunte, selecciona «Reemplazar los archivos en el destino».
5. No reemplaces ni elimines .env.local, .vercel ni node_modules.
6. Abre PowerShell en C:\Users\Usuario\profe-en-movimiento-5 y ejecuta:

   npm run lint
   npm run build

7. Si ambas verificaciones terminan correctamente, publica:

   npx vercel@latest --prod

No hace falta ejecutar una migración SQL para esta corrección.

PRUEBA RECOMENDADA
1. Ingresa como estudiante.
2. Abre Recursos para estudiantes > Deportes.
3. Genera «Técnica del tiro libre en baloncesto».
4. Mantén marcada la opción «Incluir apoyo visual».
5. Verifica que aparezcan hasta dos imágenes pertinentes con su crédito. Si
   Wikimedia Commons no ofrece una imagen adecuada, el reporte debe continuar.
6. Pulsa «Imprimir o guardar en PDF» y espera unos segundos para que las
   imágenes terminen de cargar.
7. Verifica que el PDF tenga exactamente 3 páginas.
8. En la página 1 comprueba: nombre, Unidad Educativa, nivel, grado/curso,
   tema y fecha.
9. Comprueba que la mano guía aparezca al costado del balón y que los
   jugadores de los espacios de rebote puedan entrar cuando el balón salga
   de las manos del lanzador.
   En «Errores frecuentes», debe indicar que el error es impulsar o desviar
   el balón con la mano guía, no mantenerla al costado.
10. Comprueba que las tres páginas muestren el encabezado institucional con
    el logo, «PROFE EN MOVIMIENTO 5.0», «DEPORTES EN ACCIÓN · RECURSO
    EDUCATIVO PARA ESTUDIANTES» y el número de página.
11. Comprueba que el PDF no cree una cuarta página vacía.

NOTA
La Unidad Educativa se obtiene del perfil estudiantil existente. Si el perfil
no tiene ese dato, la impresión mostrará «No registrada».
